# Research Package Definition

This repository qualifies as a research package because one explicit systems engineering decision question is connected to a named empirical source, declared objectives, executable analysis code, complete derived evidence, robustness analysis, visual evidence, reproducibility checks, and bounded interpretation.

## Core question

Which observed alternatives remain non dominated when cement is minimized while slump and 28 day compressive strength are maximized?

## Robustness question

How much does that decision set change when slump is omitted as an objective or represented as an eligibility threshold?

## Empirical core

Exact Pareto dominance over 103 observed laboratory experiments plus three alternative decision formulations.

## Released result

The baseline contains 23 non dominated observations.

Alternative treatment of slump produces frontiers of 10, 10, and 8 observations with baseline retention of 43.5%, 43.5%, and 34.8%.

## Required evidence chain

A release is considered complete only when these agree:

- public source metadata;
- packaged objective table;
- baseline frontier;
- sensitivity results;
- machine readable summaries;
- analysis code;
- tests;
- figures;
- scientific report;
- README;
- paper blueprint;
- validity boundaries.

## Boundary

The repository supports transparent decision analysis over the named observations. It does not prescribe a concrete mixture and does not model the full set of variables required for field design.
